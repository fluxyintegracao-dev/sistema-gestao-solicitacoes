# Workspace - Contexto Compartilhado

## Objetivo

Esta pasta guarda o contexto deste repositorio para sessoes compartilhadas com outros repositorios do mesmo workspace.

Ela serve para:

- manter contexto local do repositorio
- registrar integracoes ativas
- registrar ownership
- registrar handoff
- facilitar continuidade entre chats

## Estrutura

- `PROTOCOLO_AGENTES.md`
  - processo obrigatorio para multiplos agentes no mesmo repositorio
- `QUADRO_AGENTES.md`
  - painel diario com sessoes, ownership, andamento, finalizados e pendencias
- `REPO_CONTEXTO.md`
  - papel deste repositorio no workspace
- `INTEGRACOES_ATIVAS.md`
  - contratos de integracao com outros repositorios
- `OWNERSHIP_ATIVO.md`
  - reserva atual de arquivos e escopos
- `HANDOFF_GLOBAL.md`
  - resumo de entregas e proximos passos
- `SESSOES_ATIVAS.md`
  - registro de sessoes abertas e foco de cada uma
- `PROMPT_SESSAO_WORKSPACE.md`
  - texto base para abrir uma sessao multirrepositorio

## Importante

Esta pasta deve ter um espelho equivalente:

- no outro repositorio participante
- e idealmente em uma pasta central no workspace

Assim o contexto pode sobreviver a troca de chat, troca de sessao ou troca de agente.
