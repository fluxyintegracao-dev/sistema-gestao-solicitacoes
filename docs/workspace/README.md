# Workspace Compartilhado

Esta pasta e usada somente quando uma sessao multirrepositorio for explicitamente aberta.

- `REPO_CONTEXTO.md`: responsabilidade deste repositorio;
- `PROTOCOLO_AGENTES.md`: processo de coordenacao;
- `OWNERSHIP_ATIVO.md`: arquivos reservados;
- `SESSOES_ATIVAS.md`: sessoes abertas;
- `QUADRO_AGENTES.md`: andamento atual;
- `HANDOFF_GLOBAL.md`: proximo passo entre repositorios.

Arquivos de controle devem refletir apenas o estado atual. Historico concluido fica no Git.
