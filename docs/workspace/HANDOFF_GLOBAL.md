# Handoff Global

## Objetivo

Registrar o estado mais recente do trabalho para que outra sessao ou outro chat consiga continuar sem perder contexto.

## Modelo

```md
## Handoff
- data:
- sessao:
- escopo concluido:
- repositorio:
- arquivos alterados:
  - caminho/do/arquivo
- validacao executada:
  - comando
- riscos conhecidos:
  - descricao
- proximo passo recomendado:
  - descricao
```
