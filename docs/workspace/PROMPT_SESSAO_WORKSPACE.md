# Prompt Base - Sessao no Workspace

Use este texto ao abrir uma sessao na raiz do workspace para auditoria, coordenacao ou integracao entre repositorios.

```text
Esta sessao esta trabalhando em um workspace com mais de um repositorio relacionado.

Repositorios envolvidos:
- fluxy-core
- fluxy-ops

Leia primeiro:
- AGENTS.md do repositorio principal em foco
- docs/COLABORACAO_CODEX.md do repositorio principal em foco
- docs/COLABORACAO_WORKSPACE.md
- docs/workspace/REPO_CONTEXTO.md
- docs/workspace/INTEGRACOES_ATIVAS.md
- docs/workspace/OWNERSHIP_ATIVO.md
- docs/workspace/HANDOFF_GLOBAL.md

Regras:
- nao editar arquivos sem ownership explicito
- ler o AGENTS do repositorio alvo antes de editar nele
- manter o handoff atualizado
- preferir uma sessao por repositorio para implementacao
- usar a sessao de workspace principalmente para coordenacao e auditoria
```
