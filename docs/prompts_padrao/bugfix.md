# Prompt - Correcao de Bug

Contexto:
- sistema em producao
- correcoes pequenas e rastreaveis

Tarefa:
1. Reproduzir o bug.
2. Localizar causa raiz.
3. Corrigir com menor impacto possivel.
4. Validar com build/teste rapido.

Checklist:
- nao alterar regras de negocio sem motivo
- nao quebrar permissoes
- documentar comportamento corrigido
